# 1907 대구 교실 방탈출

국채보상운동(1907, 대구)을 주제로 한 5, 6학년 교실 방탈출 웹앱입니다. 서버와 로그인 없이 HTML 파일 하나로 작동합니다.

## 수업 흐름
1. 학생이 자기 기기에서 앱을 열고 자기 번호를 누릅니다.
2. 자기만의 단서 카드를 읽고 질문의 빈칸을 채우면 비밀 숫자 하나가 나옵니다.
3. 모둠원 다섯 명의 숫자를 자리 순서대로 모아 모둠 금고를 엽니다.
4. 금고가 열린 기기에서 생각 나누기, 모둠 의연 증서, 모둠 호외를 완성합니다.
5. 선생님 화면에서 학생 번호를 눌러 1,300만 원 게이지를 함께 채웁니다.

## 우리 반 설정
- 학생 번호: 1~23 중 2, 15, 17 제외 20명
- 모둠: 번호 순 5명씩 4모둠
- 바꾸려면 `index.html` 위쪽의 `STUDENTS` 배열을 고치면 됩니다.

## 쓰는 법
- GitHub Pages 주소로 열거나, `index.html` 파일을 기기에서 바로 열어도 됩니다.
- 진행 상황은 각 기기의 브라우저에만 저장됩니다. 다른 반이 같은 기기를 쓰기 전에는 선생님 화면의 '이 기기 기록 지우기'를 누르세요.
- 선생님 화면 비밀번호는 `index.html`의 `TEACHER_PIN`에서 바꿀 수 있습니다. 소스를 보면 알 수 있는 값이라 보안용이 아니라 학생이 실수로 여는 것을 막는 용도입니다.
- 검사: `tests/test.html`을 같은 주소에서 열면 25개 검사가 돌아갑니다.
