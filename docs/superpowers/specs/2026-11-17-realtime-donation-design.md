# 실시간 의연금 모으기 설계

## 왜
선생님이 약속 발표를 듣고 번호를 눌러 게이지를 채우던 방식을 없앤다. 20명이 각자 태블릿으로 동시에 접속해, 선생님 손 없이 친구들과 1,300만 원을 끝까지 채운다. 모둠 태블릿 한 대로 하는 단계는 두지 않는다 (교사: "무조건 수업 망해").

## 목표
- 모든 단계를 학생 각자 태블릿에서 한다.
- 친구 미션 퀴즈: 모둠 친구 4명의 미션 문제(4지선다)를 그 친구에게 물어 풀고 엽전 4개를 모은다.
- 엽전 4개를 모으면 '65만 원 모금함에 넣기'. 20명 × 65만 원 = 1,300만 원.
- 반 모금함 게이지가 20대에서 실시간으로 함께 오르고, 다 차면 모든 태블릿에 축하 화면.
- 의연 증서와 호외는 모둠원이 맡은 칸을 각자 태블릿에서 써서 함께 완성한다.
- 선생님 화면은 수업 중 누를 것이 없다: 실시간 현황판, 비밀번호 표, '새 수업 시작'.

## 하지 않을 것
- 로그인, 학생 계정, 개인정보 저장.
- 모둠 공용 태블릿이 있어야 하는 단계.
- 선생님이 수업 중에 눌러야 진행되는 단계.

## 방법
- 고른 것: Firebase Realtime Database (무료 Spark 요금제). 교사가 직접 이름을 들었다. HTML 파일 하나는 그대로 두고, Firebase SDK(compat 10.12.2)를 gstatic에서 불러와 databaseURL 하나로 연결한다. 웹앱 등록과 API 키는 쓰지 않는다.
- 버린 것: 모둠 기기 한 대에 모으기 (교사가 거절), 반 금고 열쇠 조각 (교사가 실시간 연결을 원함), Google Apps Script (폴링이고 배포 단계가 더 많음).
- 연결이 안 되면(또는 주소 뒤에 `?local`) 이 기기 안에서만 저장하는 로컬 모드로 돈다. 검사도 로컬 모드로 돈다.

## 데이터 (rooms/class 아래)
- `session`: 숫자. '새 수업 시작' 때 바뀐다. 기기에 저장된 값과 다르면 그 기기의 진행(me, solved, wrong, vault, vaultWrong)을 지우고 처음 화면으로 간다.
- `quiz/{번호}/{미션}`: true (친구 미션 문제를 맞힘)
- `donated/{번호}`: true (65만 원을 넣음)
- `groups/{모둠}/f/{칸}`: 글 (200자 이하)
- `groups/{모둠}/p/{번호}`: 내 약속
- `groups/{모둠}/weeks/{0~3}`: 한 달 실천 체크

## 맡은 칸
- 첫째: 줄일 것, 알게 된 사실 1
- 둘째: 모을 것, 알게 된 사실 2
- 셋째: 약속 기간(시작, 끝), 알게 된 사실 3
- 넷째: 머리기사 장소, 모둠 생각 한 문장
- 다섯째: 홍보 문구
- 모두: 내 약속 한 가지 (의연자 명단)

## 퀴즈 (미션 단서 카드에서만 답이 나오게)
- 1 광문사의 꿈: 광문사 사람들이 나라의 힘을 기르려고 힘쓴 일 → 학교 세우기
- 2 운동의 시작: 광문사 모임에서 나랏빚을 갚자고 제안한 날 → 1월 29일
- 3 서상돈의 계산: 무엇을 끊어 돈을 모으자고 했나 → 담배
- 4 남일동 부인들: 부인 일곱 명이 만든 모임 이름 → 패물폐지부인회
- 5 대구시민의 날: 1907년 2월 21일 군민대회를 연 곳 → 북후정
- 틀리면 그 문제만 8초 동안 잠기고 "○번 친구에게 물어보고 다시 골라요"가 나온다.

## 보안
- 규칙: rooms/{방} 아래만 읽고 쓸 수 있고, 칸마다 형식(숫자, 참거짓, 200자 이하 글)을 검사한다. 그 밖은 막는다.
- 저장소가 공개라 주소를 아는 사람은 모금함을 건드릴 수 있다. 수업용으로 받아들이고 교사에게 알린다.

## 빌더에게 맡긴 것
화면 배치, 엽전과 게이지 모양, 문구 세부.
